السياگ - SYAG  (PWA)

1) Mettre le jeu en ligne (gratuit, sans rien installer)
   - Va sur https://app.netlify.com/drop depuis un ordinateur.
   - Glisse tout le dossier "syag-pwa" (dézippé) dans la page.
   - Netlify te donne un lien en https://....netlify.app (crée un compte gratuit pour le garder).
   Autre possibilité : GitHub Pages.

2) L'installer sur le téléphone
   - Ouvre le lien dans Chrome sur Android.
   - Menu (3 points) > "Installer l'application" / "Ajouter à l'écran d'accueil".
   - L'icône SYAG apparaît comme une vraie application, et le jeu marche ensuite sans internet.

3) Avoir un fichier APK (optionnel)
   - Va sur https://www.pwabuilder.com, colle le lien du jeu, puis "Package for stores" > Android.
   - Tu télécharges un fichier .apk à installer ou à envoyer.
